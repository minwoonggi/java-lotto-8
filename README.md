# java-lotto-precourse

## 기능 구현사항
### 입력
- [ ] 구입 금액 입력
- [ ] 당첨 번호 입력
- [ ] 보너스 번호 입력
### 예외
- [x] 비어있는 입력값 예외
- [x] 로또 구입 금액은 1000 단위
- [x] 중복된 당첨 번호 예외
- [x] 로또의 숫자 범위는 1 ~ 45
### 출력
- [ ] 구매한 로또 번호 출력
- [ ] 로또 번호는 오름차순
- [ ] 당첨 통계 출력
- [ ] 수익률 출력
### 로또
- [x] 중복되지 않는 로또 생성
- [x] 로또 숫자 정렬
### 로또 결과
- [x] 로또의 금액 합 반환
- [x] 결과에 따른 로또의 당첨 횟수 증가
### 로또 서비스
- [x] 무작위 로또 생성
- [ ] 로또와 당첨번호, 보너스 번호 비교후 로또 결과 반환
- [ ] 총 수익률 계산
